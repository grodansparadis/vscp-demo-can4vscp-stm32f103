# CAN4VSCP STM32F103 Blinky

This demo turns an STM32F103 "Blue Pill" into a
[VSCP](https://www.vscp.org) Level I node on a 125 kbit/s CAN4VSCP bus.
It blinks an LED, sends button events, exposes registers and responds to
events through a four-row decision matrix.

Start with [getting started](getting-started.md), then see the
[hardware and wiring](hardware.md), [firmware](firmware.md),
[registers and events](registers.md), and [testing](testing.md) pages.

The [source repository](https://github.com/grodansparadis/vscp-demo-can4vscp-stm32f103-blinky)
contains the firmware, host tests and STM32CubeMX project.
